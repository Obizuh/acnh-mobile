# Contributing

Keep changes scoped to ACNH and preserve upstream/third-party notices. Include the supported game version, device/system details and reproducible steps. Do not submit ROMs, keys, saves, generated game code, translated shaders or personal logs.

Run the source-release audit before submitting. Keep local inputs and generated build products outside the public tree. Mark device-only behavior, power/temperature claims and full-build results as unverified unless actually tested. General engine changes should include the applicable host/GPU regression checks.
