# ACNH Mobile

**v0.3.24 · 构建 26，官方 Metal 4 版，要求 iOS 26 或更新系统。**

本次 main 换用 NXNative 官方渲染核心与配套着色器翻译流程，基线为 `e72a06510e6dfff4a77c49fd205a82e21cad0786`。保留原项目的图标按键、工具环、手柄、R 键和输入框唤起系统输入法，以及 `.data` 直读、事务存档、amiibo 文件导入、照片导出与震动反馈。启动页提供自定义控制器编辑，游戏内不增加打字工具栏。

本版将控制器布局、静音播放及震动选项收进可展开/收起的“个性化”，展开后保留独立卡片和原生控件。保留已有设置和控制布局，原 3.0.3 `.data` 继续使用。[更新说明](docs/RELEASE-v0.3.24.zh-CN.md)。

## 下载与使用

[Releases](https://github.com/huajiaoshu520/acnh-mobile/releases) 提供未签名的**无游戏空壳 IPA**、审计报告和 SHA256 校验文件。

空壳不含游戏程序、游戏数据、转换后的游戏着色器、key、存档或字体。项目图标是唯一的识别图片。空壳不能直接游玩，仅导入 `.data` 也无法启动；需要在电脑上使用自己的游戏程序、官方配套着色器和字体生成私人完整 IPA，再整包签名。

[构建说明](docs/BUILD.md) · [空壳补包说明](docs/SHELL.zh-CN.md)

原来的 `./setup.sh build --patched … --romfs … --shaders … --font … --work … --output …` 用法不变。已有 3.0.3 的 `ACNH-index.data` 和所有编号分卷可继续使用，放在应用的 `Documents/ACNHMobile`，不解压、不并入 IPA。也可以在应用启动时选择对应文件夹。

## 操作

左摇杆移动；工具图标按住滑动选择；手机、表情、背包、拾取、跳跃、返回和互动保持原图标及位置。右侧相机图标拖动调整游戏支持的视角。R 打开聊天后识别输入界面；命名时点击游戏输入框，识别后唤起系统输入法。输入后由用户在游戏里确认，不自动确认不可修改的名字。

拍照获准且成功导出到手机相册后才移除该次应用内照片；拒绝或导出失败时保留在应用内。amiibo 通过用户选择的文件读取；NFC 硬件探测受实际签名宿主权限限制，不能据此保证实体卡可以直接在游戏中使用。

## 验证范围

已完成 Release 编译、空壳无游戏内容与版本校验，以及使用自备文件补包的本机验证；Mac 启动到机场，数据读取、存档、文字、amiibo 和照片相关回归通过。完整手机游戏流程、手柄、输入法以及相册/NFC 权限仍需真机验证，不承诺解决所有发热或画面问题。

GitHub Actions 在 main 运行 **Build game-free iOS shell**，勾选 publish 可在构建和审计通过后创建对应版本的 Release；不勾选只生成构建产物。已有 Release 不覆盖。本次发布 iOS 26 官方 Metal 4 空壳，历史发布保留。

## 本地一键入口

Mac 用户可双击项目根目录的「一键生成完整IPA.command」「一键生成IPA和数据包.command」。选择自备游戏目录与 prod.keys，自动补齐可安装依赖，完成提取、程序改写和官方着色器转换；也支持复用已有匹配输入。版本自动读取项目配置。详见 [一键构建说明](docs/ONE-CLICK.zh-CN.md)。
