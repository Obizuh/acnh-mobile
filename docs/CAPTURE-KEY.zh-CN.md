# 专属截图键

从 0.3.40（构建 42）开始，专属控制器底部中央新增 Switch 风格截图键（方框内圆圈）。轻点一次保存当前游戏画面，不包含触屏按键；按住不会连拍。以专属为基础的自定义布局也可以调整此键的位置、大小和复位。

截图与游戏相机共用本地 PNG 写入和相册导出路径：允许添加照片并保存成功后，只保留相册里的照片；拒绝授权、宿主不支持授权或导出失败时，保存在应用 Documents/photos 中。已经授权的设备通常不会再次弹窗。通用控制器不增加此按钮。

验证：iPhone/iPad Release 编译；原有游戏相机 PNG 颜色和尺寸、非法输入、写入失败测试；新增直接图像输入的非标准尺寸测试。相册授权与真机触控仍需手机实测。
