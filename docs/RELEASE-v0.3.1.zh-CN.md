## ACNH Mobile v0.3.1 · 构建 3

- 合入官方 NVN 指令录制内存边界修复，避免相邻指令记录互相覆盖。
- 合入官方 Vorbis 多声道音频解码与缓冲区大小修复。
- iPhone、iPad 虚拟按键左上角「－」右侧增加 L 键；原跳跃图标保留，两个入口均发送 L。
- 保留原图标布局、R 键输入法及外置 .data 直读。官方着色器链未变，原配套着色器和 3.0.3 数据包可继续使用。

发布文件仅为空壳，不含游戏程序、游戏数据、转换后的游戏着色器、key、存档或字体。需要用户使用自己的文件补包并签名。手机实际操作及完整游戏流程仍需真机验证。

### 验证

iPhone/iPad Release 编译和 IPA 完整性检查通过。官方新增指令边界回归通过，旧录制器的 496 字节相邻槽覆盖问题已在对照测试中复现、修复后消除；Vorbis 两种解码配置回归通过。NVN 全套 100 项检查中仍有一项原有计时检查失败，旧版同样存在，并非本次新增。手机按键位置和完整游戏流程仍需真机验证。

官方修复来源：[NVN 指令边界](https://github.com/seedds/nxnative/commit/0b3c7b1200f38fa914ec4337259e45fc40b42c01)、[Vorbis 多声道](https://github.com/seedds/nxnative/commit/e10277be9ad0a961b90b1f6cca822e37a0d331d2)。
