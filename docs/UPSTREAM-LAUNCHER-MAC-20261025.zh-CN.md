# 启动页、帧缓冲和 Mac 打包集成

版本：0.3.39，构建 41。本次为本地集成，尚未推送、发布。

- NXNative `7d368c4249d1`：资源表和零复制缓冲区释放使用独立 autorelease pool，避免客体线程长期保留已释放的 Metal 缓冲区。
- `a1886130a6fa`：可选帧缓冲、画面快照、帧节奏和挂起等待。默认关闭，iOS 位于“个性化”中；包含官方测试。
- 新 iOS 启动页采用原生导航列表，左侧游戏信息、右侧连续设置列表；个性化内容原地展开，控制器布局与调整对象相邻。原有专属按键、文字输入及数据包格式继续保留。
- `ffcd91098611`、`7a3b95873bf1`：独立 Mac 应用启动器、打包器、模块检查和提示修正。新增 `./setup.sh mac-app`，复用项目图标和统一版本号。
- `1159ccc67562`：仅采用通用 GPU code 版本查询与着色器字典类型修正；不引入其他游戏修改或更换着色器链。
- `641799d51b66`：仅补齐独立 host 测试的链接桩。

## 验证

- iPhone／iPad Release 编译通过，完整 IPA 的 ZIP 校验、版本号和构建号检查通过。
- 41 项构建／设置／Mac 打包工具测试通过；包括模拟宿主启动、模块缺失、信号转发、日志轮换和复制降级。
- NVN 118 项、帧节奏 51 项、显示裁剪 34 项通过；官方帧缓冲复制、挂起和两种编码线程配置共 38 项通过。
- 缓冲区生命周期 33 项通过；将三处函数恢复旧实现后出现 16 项预期失败，证明该测试可以检出原问题。
- 地图对照：私有测试副本仅绕过本地 alpha 运行时逻辑，仍出现密集斑块，恢复后正常；继续保留现有补丁。此对照仍使用本地匹配着色器，不冒称本轮重新制作了纯官方着色器。
- host 测试套件通过。Mac 独立应用签名验证通过，使用存档副本启动并进入游戏，帧缓冲开启时地图可以显示。
- 从已准备文件制作 Mac 应用已实际完成；原始 NSP 全流程本轮未重新完整运行。尚未进行 iPhone 实机验证，也不宣称改善 iPhone 的帧率、温度或续航。

Mac 制作教程见 [MAC-APP.zh-CN.md](MAC-APP.zh-CN.md)。本机验证产物最低 macOS 为 27.0；其他环境以产物实际最低系统要求为准。
