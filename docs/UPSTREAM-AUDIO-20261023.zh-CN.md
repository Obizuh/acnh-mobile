# NXNative 音频后台恢复修复（本地合入）

来源：[fe23c10](https://github.com/seedds/nxnative/commit/fe23c103075711f090760cd25bfe6c088ede7274)。音频 watchdog 在取得 `g_aos_lock` 后再读取时钟，与后台恢复时重新启动 AudioUnit 并更新时间戳的操作保持同步，避免旧时间减去新时间发生无符号下溢、误判停播并重复重启正常输出。

验证：音频前后台切换与 20 个缓冲的设备回调中断恢复通过；SPSC 队列追加和释放 100,000/100,000，failed=0。新增 watchdog 锁同步回归在修复前失败（1 次采样、0 次受锁保护），修复后通过（1 次采样、1 次受锁保护）。iPhone/iPad Release 编译及安装包完整性检查通过。手机后台恢复效果仍需真机确认。

同时按官方 d2ff028 的更正补充 seedds 版权署名，保留原有 jhaizhou 署名和 MIT 条款。未合入新的启动设置页，沿用现有界面、按键和输入流程。未改动着色器链或 `.data` 格式；此次上游提交没有直接修复泥土路图标颜色。
