# 纹理视图颜色修复（v0.3.6 / 构建 8）

来源： https://github.com/seedds/nxnative/commit/a08bbdd3ba144a6de4db39576cd0512786573eb7

合入官方纹理视图通道组合、mip 数量边界、可写 image 视图及带通道变换时的渲染合并限制。上传的 RGB565 类纹理按格式修正红蓝映射；Metal 已渲染的纹理维持自身通道顺序。同步该提交的图形测试与弱 host 桩，不修改游戏资源或着色器缓存。

针对泥土路选项预览偏蓝、实际铺地正常的报告提供测试版。该现象符合纹理格式映射遗漏，但尚未在同一存档菜单复现并验证，不把 GPU 单元测试当成游戏画面修复证明。

验证：Metal API Validation 开启，官方颜色通道测试 203 项通过，纹理视图 mip 测试 34 项通过。额外 t_pfv 格式视图检查失败 1 项；修复前 HEAD 对照也失败 1 项，保留这一已知限制。启动页与通用/专属控制器功能保留，原 .data 无需更新。
