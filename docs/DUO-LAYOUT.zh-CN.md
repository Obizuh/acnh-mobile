# Duo 屏幕适配

内外屏均使用横排启动页；游戏保持完整 16:9 画面，在当前窗口安全区域内等比放大，剩余区域留黑边。专属控制器保留排列，左右按键各向中间微调 2.5% 画面宽度；按键与摇杆以点为单位绘制，不跟随画面横纵拉伸。

通过 UIKit 的 UIHingeInteraction 判断设备是否支持铰链，不通过屏幕尺寸或机型名称推测。仅此类设备将控制器坐标系对齐到游戏画面，避开系统报告的遮挡区域。自定义布局编辑器使用相同坐标系。普通 iPhone、iPad 保留原有画面范围与默认按键位置。

窗口变化时重算画面和控制器位置，清除旧触摸输入；Metal drawable 随当前显示屏的 displayScale 更新。不强制展开、不重启游戏，也不修改渲染核心或着色器。

使用 Xcode 27.1 SDK 编译才启用铰链和 reserved-region API；运行时也有 iOS 27.1 可用性判断。最低部署版本仍为 iOS 26。旧 SDK 构建会继续使用原有布局，无法启用这套 Duo 专用适配。

已完成 Release 真机目标编译、安装包 CRC/版本校验、画面比例与遮挡避让几何检查、自定义布局数学回归检查。未进行 Duo 真机折叠、触摸或实际游戏切换测试；最终效果需真机验证。

参考：[Apple 适配说明](https://developer.apple.com/iphone-duo/prepare/)、[设备规格](https://www.apple.com/iphone-duo/specs/)。
