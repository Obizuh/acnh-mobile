## ACNH Mobile v0.3.3 · 构建 5

合入 NXNative 官方通用 NVN 渲染优化：

- iOS 默认使用独立线程执行 Metal 编码。
- 较大的 uniform 数据由后台线程复制，合并跨渲染通道的延迟更新，减少重复处理。
- 显存地址查找使用两级缓存。
- 新增 GPU 耗时诊断，默认关闭。

保留原触屏按键、R 输入法、图标、存档及外置 `.data` 直读。着色器翻译链未变，原配套着色器和 3.0.3 数据包可继续使用。

### 验证与范围

Mac 和 iPhone/iPad Release 编译、IPA 完整性及图标检查通过。实际动森运行 75 秒，进入机场并正常显示中文对话；uniform shadow 校验 4,000 次一致、0 次不一致，GPU 耗时诊断正常输出。

官方 NVN 回归在编码线程开、关两种配置下均通过 99/100 项，唯一失败仍是原有 GPU 时间戳检查。手机发热、帧率及长时间运行效果仍需真机对比，本次不承诺具体性能或降温幅度。

发布附件仅含 GitHub Actions 构建的无游戏空壳 IPA、审计报告和 SHA256 校验文件；不含游戏程序、数据、keys、存档、字体或转换后的游戏着色器。请用自备文件制作完整 IPA 并签名安装。
