# iOS 跨应用存档文件协调（0.3.41 / 43）

游戏提交先克隆工作目录，再整体原子交换 Documents/save，保护中断与空间不足时的存档完整性。现在仅在 iOS 的原子交换外加 NSFileCoordinatorWritingForReplacing，通知文件提供者目录替换；协调失败时拒绝提交，不退回未协调或逐文件写入。原有写失败拒绝、工作副本与回退逻辑保留。

针对用户报告 SideStore 游戏保存后岛屿档案失去 save 访问权限。此改动不能证明 iOS 一定保留第三方书签，仍须手机完成“修改器读写→游戏保存→修改器重读”验证。不要宣称本机测试已覆盖跨应用沙盒授权。

验证包括原子目录交换、替换失败保留旧数据、既有保存事务与 CommitList 回归，以及 iOS 完整 IPA 构建。未涉及游戏资源、密钥或图形更新，不自动推送发布。
