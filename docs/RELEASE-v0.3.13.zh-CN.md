## ACNH Mobile v0.3.13 · 构建 15

- 新增自定义控制器：启动页选择「自定义」，再选择通用或专属作为调整对象，进入「调整位置与大小」。拖动控件调整位置，选中后用滑块调整大小（50%–200%）；编辑面板也可拖动，避免挡住按键。
- 支持保存、取消和复位。两种调整对象分别保存，复位只恢复当前对象的初始位置和大小，点击保存后生效。通用方向键作为整体调整，右侧无形视角滑动区保持官方行为；通用自定义以官方 3D 布局开始。
- 专属左摇杆恢复最初原始大小，工具环滑选距离不变。内置通用和专属布局不受自定义调整影响。
- 新增「静音模式下播放声音」，默认关闭；打开后使用系统 Playback 音频模式，前台游戏在手机静音时也可出声，仍遵守系统音量和音频中断。
- 启动页标题和说明支持简体/繁体中文与英文，说明文字另支持日文，跟随设备/应用首选语言。页面语言与游戏语言设置独立。
- 合入 NXNative 官方计算式几何着色器路径及配套通用绑定、反射、翻译器更新，同时纳入远距离跳转表基址查找和资源读取兼容改进。

保留此前泥土路预览颜色、影片结尾与音频恢复修复，以及输入法、事务存档、amiibo、照片导出等功能。仍要求 iOS 26，没有新增 iOS 18 或老机型兼容支持。

### 数据与构建

原 3.0.3 外置 `.data` 数据包无需重做。本版几何渲染使用新配套着色器链 `ade9bce36598`，旧着色器缓存不能混用，需要随完整 IPA 更新或自行重新构建。私人完整 IPA 的体积因此有所增加。

发布附件仅含 GitHub Actions 从 main 构建的未签名无游戏空壳 IPA、审计报告和 SHA256 校验文件，不含游戏程序、数据、keys、存档、字体或转换后的游戏着色器。空壳需用自备文件制作完整 IPA 并签名，不能仅导入 `.data` 游玩。

### 验证与范围

iPhone/iPad Release 编译、IPA 完整性、版本、设置和编辑器入口检查通过。自定义几何检查覆盖原始位置与复位、归一化移动、独立控件、缩放边界、异常数据和独立保存；启动设置检查通过。简体/繁体/英文与日文说明选择检查通过。

官方几何后端 95 项、顶点绑定 43 项、绘制跳过 38 项、颜色映射 203 项、纹理层级 34 项通过；动森 Mac/iOS 基础着色器 9,766 个全部编译成功。Mac 隔离测试运行 75 秒，进入机场并正常显示中文对话，主动终止后正常退出；只有之前已有的两条纹理类型提示。

自定义编辑器的真机拖动、缩放、操作手感、静音开关实际效果以及岛上复杂场景和长时间游戏仍待测试，不承诺性能或降温改善。
