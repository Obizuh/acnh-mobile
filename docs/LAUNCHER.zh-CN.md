# iOS 启动设置页（v0.3.5 / 构建 7）

基于 NXNative 的启动页提交 2f69480 和后续界面整理 f73c1e3 接入。原 `.data` 导入及校验完成后显示设置页，程序预加载可以继续；点击“开始游戏”才创建游戏画面、原触屏按键和帧率显示，开始运行游戏。未加入按键编辑或额外打字工具栏，原 R 输入法保留。

动森当前提供运行模式、游戏支持的语言、显示帧率、性能信息面板。默认保持主机模式、简体中文、关闭两种性能显示；不提供本游戏没有对应支持的强制帧率或渲染比例选项。中文系统下使用中文标签，设置在点击开始后保存。配置文件 env.txt 中明确设置的选项优先，页面上不能修改。

`Documents/env.txt` 中设置 `DM_LAUNCHER=0` 可跳过页面。原有完整 `.data` 可继续使用，无需重新生成。设置页不改动存档；本版同时包含已验证的官方音频后台恢复修复。

验证：动森设置过滤、语言与默认值检查通过；设置记忆、无效旧选项回退和 env 文件优先级的模型运行检查通过；iPhone/iPad Release 编译通过，包内启动页入口、launcher.json、版本、图标和 ZIP 完整性已检查。尚未在真机上操作设置页，不宣称真机显示、切换模式或语言效果已通过。

来源：https://github.com/seedds/nxnative/commit/2f69480260068c0979ee42a1c31b420eecfd27e2 和 https://github.com/seedds/nxnative/commit/f73c1e3ec65c4426996e313dbcfffbcf0760be7b。

启动页新增“控制器布局”：默认“专属”使用原动森图标布局、工具环和 R 系统输入；“通用”使用 NXNative f73c1e3 官方控制器，保留其 2D/3D 切换与实体手柄逻辑。选择随启动设置保存，下次启动生效；通用布局的 R 是普通手柄 R 键，不包含专属布局的系统输入辅助。两套布局仅实例化当前选择的一套，后台重置也只发送到该套。
