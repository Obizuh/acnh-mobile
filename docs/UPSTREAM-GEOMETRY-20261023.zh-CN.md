# 官方几何着色器路径（v0.3.8 / 构建 10）

上游检查至 eab15b5a7e33，按需合入 bb585cd5f2e9 的通用 NVN 几何渲染、反射、翻译器源码与测试，包含其依赖的单纹理绑定、动态纹理数组及整数片段输出等通用基础。未覆盖应用按键、系统输入法、相册、amiibo 或存档代码。

新的路径先捕获顶点输出，再以计算着色器展开几何图元并压实输出，最后通过原片段着色器绘制；原有只写层号的几何折叠优化保留。使用官方锁定翻译器，动森的配套 Mac/iOS 着色器需重新编译。几何数据临时空间上限 256 MiB，输入上限 4,194,304，超限报告并拒绝；变换反馈与曲面细分组合等仍有限制，不宣称所有游戏或所有几何效果已支持。

同批纳入 7ca41c61f4a5 的通用远距离跳转表基址查找，以及 0c03385dd95e 的 Unity 2020 计算着色器资源格式读取。其他游戏的专用 SDK 地址调整、内存配置及游戏文件不纳入。脚本 cli 环境恢复补丁针对上游完整 NSP 脚本，本项目不运行该入口，准备器已显式复制环境字典，未引入整套其他游戏入口。

原外置 .data 只承载 RomFS，本次不更改其格式或内容，继续使用；旧配套着色器不能混用新版链，需随新版完整 IPA 或自行构建重新生成。本项没有新增 iOS 18、旧 Metal 或 A12/A13 兼容支持，安装下限保持 iOS 26。
