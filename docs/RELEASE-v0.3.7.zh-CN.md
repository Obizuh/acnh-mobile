## ACNH Mobile v0.3.7 · 构建 9

- 合入官方渲染状态恢复修复：在预编译预测、延迟绘制和融合检查恢复状态后，重新确认顶点/片段等阶段的着色器组合，避免环形缓存槽被复用后使用错误组合。
- 合入 H.264 影片结尾修复：归还输出缓冲后继续排空剩余画面，结束包先输出排队图像，避免结尾黑帧或无法结束。动森已有 VP9 与原生影片处理保留，本项不承诺其现有片头性能改善。
- 构建流程允许使用本机 Metal 编译器和 spirv-cross，版本不同会提示；翻译器匹配与缺失工具仍严格检查，不修改官方着色器链版本。

保留 v0.3.6 泥土路预览颜色修复、启动设置页、通用/专属控制器选择、专属 R 系统输入、音频恢复以及原存档、amiibo、照片导出等功能。已有 3.0.3 `.data` 和配套着色器继续使用。

### 验证

实际生产渲染代码的环形缓存复用恢复回归通过；颜色映射 203 项、纹理层级 34 项、编译器兼容规则 3 项和游戏准备检查 4 项通过。iPhone/iPad Release 编译、IPA 完整性、版本、启动配置和修复入口检查通过。H.264 排空尚未在动森实际影片中单独触发验证，真机游戏效果仍需复测。

发布附件仅含 GitHub Actions 从 main 构建的未签名无游戏空壳 IPA、审计报告和 SHA256 校验文件，不含游戏程序、数据、keys、存档、字体或转换后的游戏着色器。使用自备文件制作完整 IPA 后签名；空壳不能仅导入 `.data` 直接游玩。
